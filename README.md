# Inteligência Comercial | Power BI

## Sobre o projeto

Projeto de Business Intelligence desenvolvido em Power BI para transformar dados comerciais em informações estratégicas, facilitando o acompanhamento de resultados, a identificação de oportunidades e a tomada de decisões orientadas por dados.

O dashboard reúne diferentes perspectivas do negócio em uma experiência interativa e organizada.

## Objetivos

- Acompanhar indicadores de desempenho comercial.
- Analisar vendas, faturamento e rentabilidade.
- Compreender o comportamento e a evolução da base de clientes.
- Avaliar o desempenho dos vendedores.
- Identificar tendências, oportunidades e pontos de atenção.

## Visões do dashboard

- **Executive:** visão geral dos resultados e dos principais indicadores.
- **Sales:** análise do desempenho de vendas.
- **Customers:** acompanhamento e análise da base de clientes.
- **Seller:** avaliação do desempenho comercial dos vendedores.
- **Insights:** identificação de tendências e oportunidades para apoiar decisões estratégicas.

## Tecnologias e ferramentas

- **Power BI Desktop:** desenvolvimento do dashboard e visualização dos dados.
- **DAX:** criação de medidas e indicadores analíticos.
- **Power BI Project (PBIP):** organização dos arquivos do relatório e do modelo semântico.
- **Git e GitHub:** versionamento, colaboração e controle das alterações do projeto.

## Estrutura do projeto

- `.pbip`: arquivo de projeto utilizado para abrir o relatório no Power BI Desktop.
- `.Report`: arquivos relacionados ao relatório e à sua estrutura visual.
- `.SemanticModel`: arquivos relacionados ao modelo semântico e à lógica dos dados.
- `.gitignore`: definição dos arquivos que devem ser ignorados pelo Git.

## Como executar

1. Clone este repositório para sua máquina.
2. Abra o arquivo `.pbip` no Power BI Desktop.
3. Caso necessário, configure as fontes de dados e atualize as consultas.
4. Atualize os dados e explore as páginas interativas do dashboard.

## Versionamento e colaboração

O projeto utiliza Git e GitHub para organizar o desenvolvimento colaborativo, registrar alterações por meio de commits e integrar atualizações entre branches.

As alterações são desenvolvidas e validadas antes de serem incorporadas à branch principal.
